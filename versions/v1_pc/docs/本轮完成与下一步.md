## 接下来在共用电脑上执行

1. 解压续做包，安装锁定依赖，执行 `python run.py selftest`，再开GUI做文件和ROI操作。
2. 在Vivado Hardware Manager确认AX7035B已下载本包保留的正式bitstream；断电后重新下载。
3. 确认COM口，先用GUI对一张图做“FPGA实测”，查看CRC与mismatch=0。
4. 执行 `python run.py board --port COM10 --split tuning`，然后 `python run.py board --port COM10`；COM10换成实际端口。固定同一套参数，不因测试结果临时改参。
5. 保存每张request/response、FPGA图、差异图和批量CSV。把新runs目录交回来即可继续核查。
6. 实际拍摄虚构面单并验证摄像头预览/拍摄；无可信真值的相片只记解码结果。
7. 需要满足256×128上限、独立每拍1像素指标和实板停止位注入时，分别立项验证，不把当前核仿真/旧板级报告当作新验收。
8. 最终补报告、PPT、视频、干净目录复现和真实签收。本包不宣称整个竞赛项目已完成。

## 本轮环境限制

此执行环境可跑Python和Icarus；没有Vivado和用户开发板，不能新出已验证bitstream或真实串口数据。GUI代码通过语法检查，但当前图形显示连接受限，未完成界面运行验收；真实Windows显示、摄像头、COM连接仍需现场验收。
冻结后若修改算法、依赖版本或数据，工具会拒绝沿用旧参数记录。应保留旧结果、新建实验版本，记录修复原因，并全量重跑；不通过修改旧报告消除差异。
