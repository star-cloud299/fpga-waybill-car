# 基础接口与扩展边界

基础版保持已验收正式V2：A6 6A请求，6A A6响应，版本2，115200/8N1、CRC16-CCITT-FALSE。RGB565像素高字节先发，其他多字节字段按protocol.py。基础模式1灰度、2固定、3自适应3x3、4自适应15x15；默认4。模式5作为可选扩展仍在同一正式bit内。

软件参考、RTL和原bit源文件不做破坏性改动。基础界面只展示模式1至4；扩展界面展示五模式并保留解码辅助自动ROI。自动ROI不读取期望文本，但会使用预解码信息，不与原固定ROI测试成绩混算。所有模式共用一次选出的输入。

新增算法建议先在benchmark外建立独立目录，加入数学参考、测试向量、边界/背压仿真，再设计新协议版本及位流。模式6判决裕量、BIT1载荷、ACK/NACK和RLE需要两端同步升级，不能借用正式V2中不存在的字段。不要把试验核的模式6支持当作已正式上板。

约束和原始bit均保留。UART接收已有两级输入同步；原时序报告仍有外部端口未配置输入/输出延迟的提示。后续约束完善须区分异步UART、板外复位和观测LED，不能用全局false_path掩盖内部时序问题。新约束和新bit必须重新实现、检查CDC/复位/时序并再上板。
