# 两段直线 · 两站面单核验拍摄单

用户最新选定路线：**S → 80厘米 → A → 80厘米 → B，B站核验后停车结束。** 共2件货物，不转弯、不折返。早期四站正方形工程与交接包完整保留，不再作为本次拍摄路线。

## 摆放

1. 在平直地面标出S、A、B三点，小车中心的相邻标记间距均为80厘米，总长160厘米；前方留停车余量。
2. 小车在S点，车头沿直线朝B；摄像头固定朝车左侧，行驶中不改变镜头朝向。
3. A、B两个货箱均放在路线左侧，标签正面朝向路线。货箱不侵入车体通道。分别把车暂放到A、B停车标记，按镜头实际位置对准对应标签后固定货箱，再将车放回S。
4. A货箱贴 `cargo_A_000026000003.png`，对应A转运区；B货箱贴 `cargo_B_000026000008.png`，对应B转运区。区域牌为 `region_A.png`、`region_B.png`。只需这两件货物。
5. 标签中心与镜头等高。沿用此前A站已成功的位置、大小和对焦；黑条完整、左右白边完整、无反光，并在停车拍摄时保持静止。不要重新开展相机或无线的反复排查。

## 启动与拍摄

1. 先关闭电脑的旧四站后台，再启动本工程 `host/START_BACKEND.cmd`。电脑和ESP接同一2.4GHz热点，后台监听8266。
2. FPGA运行两站直线位流，实时HDMI画面正常；电机接通后先保持待命。ESP已保存的网络若未变，无需重新配置。
3. 后台或ESP重新连接后，按FPGA RESET建立新一轮HELLO；等画面和本轮0/2待命，再将小车置于S起点。
4. 按KEY1一次：小车从S直行到A，停车传图核验；A匹配后继续直行到B，停车核验；B匹配后显示“任务完成，已停车”，本轮2/2，不再移动。
5. 连续拍到S出发、A停车及A区匹配、继续前行、B区匹配及最终停止。每站图像无线传输约20秒，等待期间是实际采图核验过程。
6. 如需错误演示，将A、B两个货箱交换，RESET后从S重新开始，应在A显示区域错误并停车。行驶时KEY2为急停，释放不会自行重启。
