# FPGA 移动面单核验小车

基于 AX7035B FPGA 的面单图像处理与条码核验项目，保留电脑联机版和智能车版两个阶段。

| 版本 | 使用方式 | 入口 |
| --- | --- | --- |
| V1 电脑联机版 | 电脑选图，经串口交给 FPGA 处理；电脑显示、解码与评估 | [V1 启动说明](versions/v1_pc/GITHUB_QUICKSTART.md) |
| V2 智能车版 | 车载 OV5640 采图、FPGA 处理、HDMI 实时显示；ESP 无线连接电脑后台解码和核验 | [V2 启动说明](versions/v2_car/README.md) |

## 智能车版本范围

当前保留版本为 **S → A → B 两段直线**，每段 80 cm，两件货物：

| 货物条码 | 转运区域 |
| --- | --- |
| `000026000003` | A 区 |
| `000026000008` | B 区 |

后轮双 MG513 电机驱动、前轮两个万向轮；轮径 65 mm，驱动轮中心距 155 mm。摄像头固定朝左，货物放在停车点左侧。处理模式为 **3×3 自适应二值化**。识别核验由电脑无线后台参与，不是 FPGA 独立完成条码解码。

已记录 HDMI 实时预览、串口采图、原图条码解码，以及两段位流 Flash 编程/校验通过。用户已观察到小车向 A 站起步；完整两站路线尚未验收。保留版本仍有用户报告的左右轮停止不同步、偏转及 COMM ERROR，上传整理未修复这些问题。已取消的 15×15/同步控制更新未收入本仓库。

## 仓库结构

```text
versions/v1_pc/       第一版源码、合成样例、固定配置及必要历史测试数据
versions/v2_car/      两段智能车源码及相对依赖
docs/                上传说明、发布说明和整理范围
SOURCE_MANIFEST.sha256  本次整理文件校验值
THIRD_PARTY_NOTICES.md 第三方来源说明
```

V2 目录下三个同级工程目录是构建依赖，不要只下载其中一个。仓库不携带 Python 安装环境、Vivado 缓存、个人实拍与运行日志。V1 的小型已验证 BIT 因历史检查入口引用而保留；V2 BIT/MCS 和完整历史 ZIP 使用 Releases 附件发布。

开发环境：Windows、Python 3.12、Vivado 2019.1，目标器件 `xc7a35tfgg484-2`。首次安装见各版本启动说明。源文件保留原始字节，避免破坏第一版冻结配置的 SHA256 检查。
